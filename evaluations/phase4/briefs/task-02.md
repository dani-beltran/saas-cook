# Add a Project child Task

Use saas-add-feature and docs/feature-briefs/phase4-project-task.md. Implement the Task contract in ordinary source with schema/migrations, a domain service, explicit oRPC DTOs/routes and typed client, localized accessible dashboard, audit/outbox, and tests. Concrete evaluator seam: packages/db/src/tasks.ts exports createTaskService(pool,hooks), returning create(actor,org,{projectId,title,operationKey}), get(actor,org,{id}), list(actor,org,{projectId,limit?,cursor?}), update(actor,org,{id,version,title?,completed?}), delete(actor,org,{id,version,operationKey}), restore(same). Table tenancy.tasks uses tenant-composite Project FK and forced RLS. Task DTO fields id,organizationId,projectId,title,completed,version,createdAt,updatedAt,deletedAt; dates ISO. Parent is immutable and Task permissions inherit exactly current Project read/update. Tasks have no independent grants or quota; positive mutations require enabled Projects policy. API tasks.{create,get,list,update,delete,restore}, REST /organizations/{organizationId}/tasks and /tasks/{id} with /restore suffix. Creation is idempotent with atomic task.created audit/outbox. Add dashboard UI under Project.
