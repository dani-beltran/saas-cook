# Phase 6 Commercial skill behavior evaluation

The explicit [Phase 6 evaluator](../../evaluations/phase6/README.md) declares five
Commercial tasks over the current files/bulk, discovery/activity, account/organization
lifecycle, analytics and independent-recovery modules. It uses two independently authored
candidate copies and actual retained Codex CLI prompts/tool/reply transcripts. Historical
Phase 4/5 evaluation results and deterministic boundary checks do not satisfy these tasks.

The declared application additions compose actual canonical services; independent
assertions invoke each candidate's added workflow with real restricted PostgreSQL/OpenFGA
and S3. Task 03 adds ownership-aware departure preparation without confirmation or freezing.
The evaluation also requires immutable import/export regression behavior, journaled cleanup,
authoritative preferences, uncertain-ingestion barriers and application restore security.
Expanded controls exercise a full backup containing team/membership/credential authority
revoked after backup, plus a delayed real FGA allow after independent epoch rotation.

Every original application source/test/configuration/migration hash is protected, along
with public briefs, an unsafe review fixture and an unrelated customization. A planned
partial stop, same-session resume, retained real Project/migration checkpoint and a
source-identical satisfied-request repeat are required for each candidate. Hidden checks
remain evaluator-owned. The unsafe seed must visibly violate all five protections before
the candidate's source-located diagnosis can pass.

model and restricted-state initialization attempts failed before author actions. Candidate 2
