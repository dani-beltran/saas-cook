# BO-00 first-slice decisions — 2026-10-21

Implementation authorized by the request to deliver BO-01/02-S1. These decisions select the documented defaults for the implementation; they are not independent security sign-off or production provisioning. Backoffice acceptance remains pending until the recorded checks and deployment review close its due gates.

- Separate Next application, hostname, host-only Strict cookies, passkey-only invited staff identity, eight-hour absolute / thirty-minute idle sessions. No password, email reset, customer identity linking or SSO fallback. A user-verified passkey is required at enrollment and sign-in. Corporate SSO is deferred; a deployment requiring SSO cannot enable this local-identity release.
- In-process explicit domain query with restricted identity/query roles in the existing application database. No customer credentials, migration, platform CLI or recovery authority in the web runtime. The independent control store owns a separate pinned operator publication. Customer readiness has no dependency on that publication.
- A single organization metadata action and exact organization grants. No global grant, customer-content browsing, directory projection or BO worker. Return only ID/name/lifecycle/local occupied and allowed seats/source timestamp/audit reference.
- Independently signed management commands establish invitations/scopes and offboard staff. Two separately configured Ed25519 authorities approve exact payload, installation/environment/recovery epoch, nonce and expiry; the web process never holds signing material or management credentials. Initial enrollment and replacement after restore require independent staff verification. The operator cannot self-grant via HTTP.
- Signed ingress assertions bind method/path/query, source IP, timestamp and exact BO origin. Explicit IPv4/IPv6 CIDRs and HTTPS required in production. Local HTTP is loopback only. No unsigned development bypass. Deployment must prevent direct-origin access and strip untrusted source headers before signing.
- Operator lifecycle fence precedes customer organization fences. Initial implementation uses one bounded shared installation operator fence, exclusive for management. This trades throughput for an auditable revocation order for the small initial cohort. No lock upgrades. Revisit per-operator fencing only with race evidence.
- Query timeout 2 seconds, lock wait 250 ms, pool cap four per web role. Lookup returns at most one organization. Future directory limits remain 50 rows/200 scanned candidates. Audit records are append-only to runtimes and include bounded case references, never free-text reason bodies, credentials or customer contents. No retention deletion executor is enabled in this slice.
- Restore changes the independent epoch and invalidates all existing operator credentials, sessions, invitations and grants by epoch comparison. Re-publication alone cannot renew their epoch. Recovery authority remains external; no readiness reset endpoint.
- Independent BO image/version and supported schema/model manifest, preserving the customer combined web/worker image and packaged CLI allowlist. Both need current image/isolation evidence.

## Evidence and release owners

Foundation and Phase 5 acceptance remain scoped to their recorded sources. Phase 6 implementation/evidence and its open release gates are linked from the development plan. This metadata-only slice needs no billing, analytics or storage credentials; current customer regressions and new operator workloads still need evidence.

Before production, deployment security must identify named staff verification/signing-key custodians, approve ingress/VPN/CIDRs and independent lockout recovery, confirm local passkeys satisfy corporate policy, set audit retention and review the restricted database blast radius. Product must approve the initial staff/org cohort. These external decisions cannot be invented by code or a passing synthetic fixture. Missing deployment configuration fails closed; no live staff enrollment or infrastructure change is authorized by this record.
